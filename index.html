🏛️ 4-Zone Medallion Lakehouse Architecture on HDFS

Built following modern data engineering principles on Hadoop Distributed File System (HDFS) and Apache Spark.

1. Bronze Zone
Raw, immutable landing for high-velocity wearable telemetry (.jsonl), multi-city food catalogs, and user fitness surveys.
2. Silver Zone
Cleaned, deduplicated, and unit-normalized Snappy Parquet tables. Mislabeled foods corrected; telemetry dropouts imputed.
3. Quarantine Zone
Dead-letter storage preserving rejected anomalies with explicit violation codes (DQ-SEM-001, DQ-PHY-002, DQ-TIM-001).
4. Gold Zone
Aggregated analytics, Atwater-verified macronutrient profiles, and Linear Programming meal allocation tables exposed to Apache Hive.
